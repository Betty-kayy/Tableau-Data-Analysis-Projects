Customer Data Analysis – Tableau Project

📊 Project Overview

This project presents a customer data analysis created using Tableau. The analysis focuses on understanding customer information based on customer type and geographical location.

🎯 Project Objective

The objective of this project is to organize and visualize customer data to make it easier to understand the customer base and identify patterns based on customer type and state.

📁 Dataset

The dataset contains the following fields:

* Customer ID – Unique identification number assigned to each customer.
* Customer Type – Indicates whether the customer is an Individual or Business.
* Customer Name – Name of the customer.
* State – State where the customer is located.

🛠️ Tools Used

* Tableau – Data visualization and dashboard development
* GitHub – Project documentation and portfolio management

🔍 Analysis

The Tableau project provides a visual representation of:

* Distribution of customers by customer type.
* Customers by state.
* Customer names and identification details.
* Comparison between individual and business customers.

📌 Key Insights

The dashboard can be used to identify:

* The proportion of individual versus business customers.
* States with higher numbers of customers.
* The geographical distribution of the customer base.
* Customer records and their corresponding customer types and locations.
